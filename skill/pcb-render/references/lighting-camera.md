# 构图、相机、灯光

全部由 `scripts/studio.py` 实现，`render_view.py` 只是命令行外壳。**这些参数是校准过的，不要每次重新扫。**

## 灯光预设

| 预设 | 用途 | 备注 |
|---|---|---|
| `pcb_hero` | **推荐**，成品图默认 | 主光 0.6 + 补光 1.05 校准；配 `--exposure -0.8` |
| `product` | 备选 | 8 盏灯，斜视角会在大面积阻焊上产生白雾，把蓝色冲淡 |
| `dramatic` | 强对比 | 适合强调金属（USB-C、屏蔽罩） |
| `soft` | 柔和 | 白底/浅色背景时用 |
| `top` | 俯视图 | 顶光为主 |

配套：`--world studio_dark --floor black`。曝光：3/4 视角 **-0.8**，俯视 **-0.2**，纯白底 +0.0。

> 如果换了灯光预设，**必须重新定曝光**：不同预设的总光量差很多（曾因 teammate 中途换标定，导致曝光基准从 -1.2 变成 0.0，整轮扫描作废）。

## 相机预设

| `--framing` | 默认 az/el | 说明 |
|---|---|---|
| `three_quarter` | -32 / 38 | 主图。方位角决定看到哪个角 |
| `top` | 0 / 84 | 不是 90°，留一点点透视更像产品图 |
| `low` | — | 低角度英雄视角，适合厚板/带结构件 |
| `detail` | — | **不推荐**：自动距离偏大 2~3 倍，改用 `three_quarter + --distance` |

镜头：主图 135 mm（默认），微距 100 mm。`--margin`：0.0（贴边）~0.05（留白）。

## 按板型选画幅

| 板型 | 主图 | 俯视 |
|---|---|---|
| 100×65（宽） | 16:9 `3840x2160` | 竖构图 `1440x2160` 或横 `2560x1574` |
| 40×60（竖） | 16:9 或 4:3，主体偏中 | 竖 `1440x2160` |
| 36×36（方） | **1:1** `2048x2048` | 1:1 `2048x2048` |

原则：**画幅比例贴近板子比例**，否则不是留白过多就是裁掉板边。方板用 16:9 会浪费一半画面。

## 微距目标点怎么算

`--target` 是**场景坐标（米）**，场景原点在板子 bbox 中心（X/Y），Z=0 是板底、板顶在 `z=板厚`。

```
scene_x = (board_x_mm - x_center_mm) / 1000
scene_y = (board_y_mm - y_center_mm) / 1000
```

其中 `x_center_mm = (board_bbox.xmin + xmax) / 2`，从 `tex/align.json` 读。
例如 36×36 板、板子坐标 (28.4, -29.5) 的电容 → `scene = ((28.4-18)/1000, (-29.5+18)/1000) = (0.0104, -0.0115)`。

**找目标点最快的办法**：先渲一张俯视图，看图里目标器件的位置，按比例换算；或者直接用 PickAndPlace 里该器件的 `Mid X / Mid Y`（单位 mm）。

`--distance`（米）建议：

| 视野 | 距离 |
|---|---|
| 整板细节（30~40 mm 板） | 0.10~0.12 |
| 局部 20 mm 区域 | 0.05~0.07 |
| 单器件特写（0603/芯片） | 0.03~0.04 |

配合 `--lens 100`。**距离比区域大小更好控制**，不要用 `--region`。

## 微距选点原则

1. 避开大元件（ESP32 模组、连接器）正中——它们会占满画面
2. 优选"颜色多样"的区域：金属 + 金色 + 陶瓷 + 丝印 + 走线
3. 让板边走一点进画面，能给"这是块板子"的空间感
4. 丝印文字完整落在画面里，能证明清晰度

## DOF

默认交给 studio 自动光圈（按分辨率缩放，4K 约 f/160，全板锐利只让背景虚化）。
产品图建议**保留 DOF**；如果发现远端板角发虚，用 `--no-dof`。

## 已知坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 斜视角整片发白 | 大面光源在哑光阻焊上的宽高光 | 换 `pcb_hero` / 降曝光 / 别用镜面阻焊 |
| 微距还是整板 | detail 自动距离偏大 | `--distance` |
| 板子太小 | 画幅与板型不匹配 | 按上表改画幅，或 `--margin 0` |
| 背景过亮/过灰 | world 与 floor 组合 | `studio_dark` + `black`；白底用 `studio_light` + `light` |
